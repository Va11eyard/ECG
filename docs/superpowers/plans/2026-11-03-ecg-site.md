# AIECG Landing Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the AIECG product landing site in `D:\Projects\ECG\site` from the self-contained kit prompt in the spec.

**Architecture:** Standalone Vite + vanilla JS + GSAP three-section site (sticky hero with a live canvas ECG trace, dark spotlight panel with canvas-drawn signal tiles, light editorial outro). No bitmaps; the only binary assets are four OFL fonts verified by SHA-256 download. All copy lives in `src/strings/en.js` for later ru/kz locales.

**Tech Stack:** Vite 6.4.2, vanilla ES modules, Canvas 2D, GSAP 3.15 (CustomEase), Node 22.12+.

**Spec:** `docs/superpowers/specs/2026-11-03-ecg-site-design.md` — contains the complete authoritative source for every file listed below. Executors read both. Materialized files must match the spec's fenced blocks byte-for-byte in behavior (formatting may survive copy).

## Global Constraints

- Zero bitmap media. All art is canvas/SVG/CSS.
- Fonts only from `assets.json`; never invent hashes; keep OFL notices.
- No em dashes, no text-arrow glyphs, no periods in titles in user-facing copy.
- No invented statistics, testimonials, or diagnostic claims; keep the screening disclaimer.
- Keep kit mechanics: 2200 ms hold + 5200 ms fade intro, `--day` variable, parallax planes, spotlight CustomEase `sl-hop`, row-height math, keyboard/touch fallbacks, reduced-motion support.
- Node 22.12+; deps limited to `gsap` and `vite`.
- Work only inside `D:\Projects\ECG\site\` and `docs/`; the repo's other uncommitted changes belong to the owner and must not be staged.
