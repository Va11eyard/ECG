# Kindred-ECG Design System — Landing, Login, Dashboard

Date: 2026-11-05
Status: draft for review
Baseline: the owner-supplied **Kindred — Dot-Matrix Hands Hero** prompt (exact recreation prompt, 2026-10-30) and the **Ритм — прототип ЭКГ-мониторинга** prototype (D:\ZeroWhats\Downloads, self-contained HTML). Owner decisions locked 2026-11-05: signal-red CTA underglow (not rainbow), all-light Kindred treatment for every landing section.

This document governs visual design for three surfaces: the landing (`site/`), the login page (`web/`), and the ER2-C dashboard (`web/`). Functional behavior of the dashboard is specified in `2026-11-05-er2c-dual-ecg-design.md`.

## 1. Design tokens (single set, all surfaces)

```css
:root{
  --bg:#f7f7f5;        /* Kindred warm off-white, page background */
  --card:#ffffff;      /* card surface (Ритм) */
  --ink:#111111;       /* primary text, pill buttons, dots #0d0d0d */
  --mute:#9a9a9a;      /* grey headline line 1, muted labels */
  --sub:#7b7b7b;       /* sublines */
  --line:#e2e6eb;      /* hairlines, card borders (Ритм) */
  --signal:#b2362d;    /* signal red: CTA underglow, Caveat accents, seal */
  --signal-l:#faeeed;
  --ok:#2e7550; --ok-c:#3c8c63; --ok-l:#edf5f0;      /* Ритм status colors */
  --warn:#8a5f10; --warn-c:#c58a1e; --warn-l:#faf4e6;
  --bad:#a8362e; --bad-c:#c2463d; --bad-l:#faeeed;
  --paper:#fffdfd;     /* ECG strip paper */
  --grid-minor:#f5dada; --grid-major:#e8b9b9;        /* Ритм ECG grid */
}
```

- Typography: **Inter** 400/500/600 (self-hosted via `@fontsource/inter` in `web/`, bundled files in `site/`), `-webkit-font-smoothing:antialiased`. Display style: weight 600, letter-spacing −0.035em for headlines. **Caveat 600** survives exactly one role: the handwriting accent (morph alt-labels, outro accent word) in `--signal` red. League Gothic, Anton and DM Sans are retired.
- Shape: pills `border-radius:999px`, cards `12px`, strips `8-10px`. Hairline borders `1px solid var(--line)`.
- Buttons: black `#111` pills, white 13.5px weight-500 text, padding 11px 20px; hover rises 1px. **Underglow**: `::before` ellipse below the pill, `left:10%; right:10%; bottom:-6px; height:16px; border-radius:50%`, background `var(--signal)`, `filter:blur(9px)`, opacity .85; hover: opacity 1, `blur(12px)`, `bottom:-9px`. Ghost variant: transparent, 1px `--line` border.
- ECG presentation (all waveforms, all surfaces): Ритм red-paper style — `--paper` background, 1 mm minor `--grid-minor`, 5 mm major `--grid-major` grid, ink waveform, 25 or 50 mm/s, 10 mm/mV, time labels and scale bar where space allows.
- Copy rules unchanged: English-first strings module, no em dashes, no text-arrow glyphs, no periods in titles, no invented statistics or partners, screening disclaimer retained.

## 2. Landing v2 (`site/`) — edited Kindred prompt

The Kindred prompt is edited as follows; everything not listed here keeps the Kindred prompt's exact mechanics (dot grid geometry, luminance quantisation, dissolve seeds, row glitch, shimmer, quiet zones, resize, `window.__render`).

### 2.1 Hero (canvas dot-matrix, the core)

- **Luminance source replaced with synthesized ECG.** The photo sheet, Higgsfield URL and `crossOrigin` pipeline are deleted. Two offscreen field canvases `fA`/`fB` (cols × rows, `willReadFrequently`) are filled each frame by stroking **ECG waveforms**: pose A = Lead I morphology, pose B = Lead II morphology, generated by the same sinus-rhythm synthesizer as the current `site/src/trace.js` (P-QRS-T gaussians, no pathology simulation). The band occupies `H·.30` height centered at `H·.56` and spans the full width with the waveform phase slowly scrolling (`t·PX_PER_SEC` equivalent, 25 mm/s feel). Strokes are drawn wide enough to survive halftone quantisation (≥ `step·.9` core width) with the existing `v = clamp((1−lum−.16)/.42)` mapping inverted appropriately so peaks land as large dots on the band's rows.
- **Motion mapping**: Kindred's reach/scale/roll become slow vertical drift (`±.012·H`), breathing scale (`1 + .04·sin`), and a gentle whole-band roll (`±.03 rad`), counter-phased left/right halves exactly like the hands. Shimmer unchanged. **Row glitch unchanged** — misaligned LED rows read as monitor interference and are kept.
- **Glitch-dissolve**: pose A ↔ B switches at Kindred's timings adapted to a full-width band: `m = mixAt(t, 3.4, 13.4, 1.6)` for the right half, `mixAt(t, 7.0, 16.0, 1.6)` for the left half, same per-dot seed rule and front sparkle. Seamless in the 20 s loop.
- **Quiet zones**: the center-fade (`cx`) and copy quiet-zone rules keep the headline, subline and CTA dot-free. The waveform dissolves before the CTA instead of fingertips.
- **Dots**: `#0d0d0d` on `--bg`. No other color in the canvas.

### 2.2 Nav, copy, capability strip

- Nav: inline SVG pulse-glyph brand mark + "AIECG" wordmark (weight 600, 15px); links `Device · Live view · Analysis · Clinics · Contact` (`#3a3a3a`, hover `#000`); black **Sign In** pill on the right → `/login` (section 3).
- Copy block at Kindred's position: `h1` line 1 grey "Every heartbeat", line 2 ink "made visible" (weight 500, −0.035em, `clamp(38px,3.75vw,68px)`); subline: "A pocket ECG that pairs with two LEPU ER2-C recorders over Bluetooth and turns their signal into a six-lead picture a clinician can read." (max-width 380px); CTA pill "Open the live view" (deploy-slot, as today) with the signal-red underglow.
- **Capability strip replaces partner logos** (bottom row): six muted text marks, same sizing/rhythm as Kindred's logos but honest — `LEPU ER2-C`, `DUAL DEVICE`, `6-LEAD MATRIX`, `25 / 50 MM/S`, `10 MM/MV`, `BLE · NO INSTALL`. No fictional partners, no invented endorsements.

### 2.3 Spotlight re-skin (all-light)

- Panel becomes `--card` white, `1px solid --line`, radius `2.5rem`, on `--bg`; eyebrow, note and row text in ink; pointer-light radial uses `--signal` at 14% opacity. Rows morph Inter 650 uppercase (default) → Caveat 600 red (alt), same GSAP CustomEase, row-height math, focus and touch fallbacks.
- Tiles re-cast as **dot-matrix tiles**: each canvas tile draws one signal motif as scanline dots (`#0d0d0d` on `--card`) echoing the hero; six motifs and set logic unchanged.
- Copy: six rows unchanged in meaning; note line: "Hover a title to see the signal in a different state."

### 2.4 Outro re-skin (all-light)

- Off-white, `h2` Inter 600 uppercase with Caveat red accent word "clear in every beat", body, black pill CTA (deploy-slot), disclaimer and font credit. No dark section remains anywhere on the page.

### 2.5 Assets

- Fonts: `@fontsource/inter` files (400/500/600) bundled or downloaded with recorded sizes/hashes; local Caveat-SemiBold.ttf kept (existing manifest entry). League Gothic, Anton, DM Sans entries removed from `assets.json` and from the page.
- Zero bitmaps throughout. No external font CDN at runtime.

## 3. Login (`web/`, route `/login`)

- Full-viewport `--bg` page, centered card (`--card`, 12px, hairline border, 380px): pulse-glyph mark, "Sign in" headline (Inter 600), email + password fields (1px `--line` borders, 10px radius, focus border `--ink`), black Sign In pill with signal-red underglow, muted secondary line linking back to the landing.
- Behind the canvas, a single **dot-matrix ECG accent band** runs along the bottom edge (the hero engine in static, reduced-motion-friendly form, single pose) — same visual language without duplicating the full hero.
- Behavior: `VITE_AUTH_URL` env slot — when set, credentials POST to it (InLab-compatible contract decided at integration); when unset, the page renders in demo mode with an amber notice "Auth is not configured in this build" and a Continue-to-dashboard bypass. No fake authentication is created.

## 4. Dashboard theming (`web/`, ER2-C live dashboard)

- Shell: `--bg`, Inter; top bar with pulse-glyph brand, device badges, Sign out. Cards `--card`, 12px, hairline borders.
- ECG lanes: each channel renders as a Ритм-style red-paper strip (`--paper`, minor/major grid, ink trace) stacked with shared time axis; lane header row carries lead name, per-lane `±` polarity pill, HR chip. 1/3/6 modes per the ER2-C spec.
- Status uses Ритм colors: lead-off `--warn-l` banner with `--warn-c` text; device disconnected `--bad-l`; sync healthy `--ok-c` chip; sync searching amber.
- Controls (mode toggle 1/3/6, 25/50 mm/s, record/export) are pill buttons; primary actions black pills with underglow reserved for the single record CTA.
- Export dialog (patient metadata, placement notes, JSON/CSV) styled as a centered card on a dimmed `--bg` scrim.

## 5. Verification

- Landing: Playwright passes at 1440×900 / 768×1024 / 390×844 — dot-matrix renders (pixel probes), dissolve cycles A→B→A within the 20 s loop, quiet zones dot-free (probe the headline rect), nav/CTA/capability strip present, spotlight morph + tile reshuffle, outro, reduced motion (static single-pose band, no raf), no horizontal overflow, console clean except the known favicon 404.
- Login: demo-mode and `VITE_AUTH_URL` paths, form focus states, accent band renders.
- Dashboard: covered by the ER2-C spec's test plan, plus a token-conformance pass (colors/typography per section 1).
